# About
The program converts temperature in celsius to its fahrenheit and kelvin equivalent.

# How to run it
It is a simple python project so it can be run on any code editor just make sure a working python version is installed on it.

# What it does
It takes celsius temperature from lab data and converts each one to its fahrenheit and kelvin equivalent using the formula provided in the code.
Fahrenheit = (°C × 9/5) + 32
Kelvin = °C + 273.15

# What I learned
I learned how to:
1.  Convert a list of Celsius temperatures to Fahrenheit and Kelvin.
2.  Use these concepts: functions, lists, tuples(used to group each temperature's three values together), loops, and unpacking(used to extract each value from the tuple for display).
